# Liana privacy policy

Last updated: 5 November 2026. Liana is made by Yehor Oblyvantsov,
Groningen, the Netherlands.

Liana does not collect, send or share any personal data. It makes no
network connections and contains no analytics or tracking.

## What Liana stores

On your computer, in your user data folder:

| File                 | Contents                                                     |
|----------------------|--------------------------------------------------------------|
| `last_settings.json` | The values of the Liana dialog, so it opens with them next time |
| `build_log.txt`      | A report of the last build: skipped features and, if a part failed, the error message, which can include folder names on your computer |

The folder is `%APPDATA%\Liana` on Windows and
`~/Library/Application Support/Liana` on macOS.

In your design: the dialog values used for a Liana system are saved inside
the Fusion design that holds it, so the system can be edited later. They
travel with the design wherever you save or share it.

Nothing else is stored, and nothing leaves your computer or your design.

## Links

The **Privacy policy** button in the Liana dialog opens this page in your
web browser. The page is hosted on GitHub, whose privacy statement applies
to that visit.

## Removing the data

Delete the `Liana` folder in your user data folder, and uninstall the
add-in. The values saved in a design hold only dialog settings; they stay
in that design until you delete it.
