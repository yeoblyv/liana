![status](https://img.shields.io/badge/status-stable-2ea44f)
![since](https://img.shields.io/badge/since-1.0.0-5b4fe0)

Pure Python part of Liana: settings, layout arithmetic, parameters and texts.

Nothing in this package imports the Fusion API, so it runs and is tested
anywhere.
