# Liana documentation

![status](https://img.shields.io/badge/status-stable-2ea44f)
![since](https://img.shields.io/badge/since-1.0.0-5b4fe0)

Liana is an Autodesk Fusion add-in that generates parametric under-desk
cable holders, an X-frame and a zip-tie mount. These pages cover using it,
how it is built, and how to contribute.
